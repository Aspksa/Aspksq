# TRACKTOR — Командный центр и Второй мозг

Интерактивная веб-версия интерфейса TRACKTOR, реконструированная по видеозаписи.

## Как запустить

Откройте [index.html](./index.html) в современном браузере. Установка Node.js, сборка и сервер разработки не нужны.

**Технологии:** HTML, CSS, JavaScript и SVG без сторонних библиотек.

## Реализовано

- **Командный центр:** список клиентов, радиальная схема, команда, уведомления, календарь, ближайшие дела, воронка за 7 дней, навыки и расписание процессов. Боковые панели прокручиваются независимо, как на видео.
- **Второй мозг:** интерактивная карта с режимами «Кольца», «Круг», «Соты» и «Силовая».
- Наведение на узел подсвечивает связи и показывает карточку. Нажатие фильтрует карту; повторное нажатие снимает фильтр.
- В командном центре узлы и строки клиентов открывают русскоязычные карточки с демонстрационными сведениями.
- Колесо мыши, экранные кнопки и клавиатура изменяют масштаб; карту можно перетаскивать.
- Поиск, переключение между отделами и папками, разворачивание и сворачивание узлов.
- Настройка угла колец, силы и размера, информационный слой, смена цветовых тем.
- Отдельные переключатели плашек и информационного слоя; сохранение пользовательских настроек в localStorage браузера.
- Экспорт карты в PNG.
- Увеличение карты относительно курсора, SVG-иконки файлов, целей и сообщений, плавное появление связей.
- Загрузка «Собираем мозг» при первом открытии и анимированные переходы между режимами карты.
- Адаптивная версия для мобильных устройств: все разделы доступны, карточки клиентов, команды, уведомлений, навыков и процессов пролистываются горизонтально.

Все подписи меню, кнопок, подсказок и уведомлений переведены на русский. **Названия организаций, проектов и имена файлов сохранены на языке оригинала.**

## Управление картой

| Действие | Результат |
| --- | --- |
| Прокрутка колеса мыши | Изменение масштаба |
| Двойной щелчок по карте | Приблизить область под курсором |
| Разведение двух пальцев на сенсорном экране | Масштабирование относительно центра жеста |
| Нажатие на шестиугольную область | Выбрать и отфильтровать проект |
| Перетаскивание | Перемещение карты |
| Наведение на узел | Связи и информация |
| Щелчок по узлу | Фильтр по выбранной группе |
| Повторный щелчок | Снять фильтр |
| \`/\` | Перейти к поиску |
| \`+\` или \`=\` | Увеличить карту |
| \`-\` | Уменьшить карту |
| \`0\` | Центрировать карту |
| \`?\` | Показать горячие клавиши |
| \`Esc\` | Закрыть карточку / снять фильтр / выйти из презентации |

## Публикация на GitHub Pages

В репозитории находится [workflow публикации](.github/workflows/pages.yml), который запускается при изменениях в ветке **main**.

1. Откройте **Settings → Pages** вашего репозитория.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. В разделе **Actions** проверьте статус задачи **Deploy TRACKTOR to GitHub Pages**.

После успешной публикации сайт будет доступен по адресу:

**https://aspksa.github.io/Aspksq/**

> Для публикации должны быть разрешены GitHub Actions и GitHub Pages. Добавление workflow не означает, что Pages уже активирован.

## Автоматическая проверка

Перед публикацией GitHub Actions запускает `node --check app.js` и `node tests/smoke.mjs`. Проверяются синтаксис JavaScript, существование управляемых элементов, базовые взаимодействия и отсутствие исходных португальских подписей в интерфейсе.

### Проверка отображения на разных экранах

Дополнительный [сценарий Playwright](tests/visual.cjs) и [workflow проверки интерфейса](.github/workflows/visual-qa.yml) предназначены для проверки ширин **390, 740, 1024 и 1440 пикселей**. Проверяются видимость всех секций, пересечения колонок, переключение экранов и раскладок, поиск и ошибки JavaScript. При выполнении GitHub Actions сохраняет снимки командного центра и трёх видов карты в артефакт `tracktor-visual-screenshots`.

Для локального запуска браузерной проверки (установки нужны **только для теста**, не для работы самого сайта):

```bash
npm install --no-save playwright
npx playwright install chromium
node tests/visual.cjs
```

**Примечание:** наличие проверки не доказывает, что она уже успешно завершилась. Проверьте результат в разделе **Actions** репозитория; сценарий использует настоящий Chromium в среде GitHub Actions.

## Структура проекта

- [index.html](index.html) — экраны и элементы управления;
- [styles.css](styles.css) — тёмное оформление, панели и адаптивность;
- [app.js](app.js) — карты SVG, переходы, анимации, поиск, обработчики событий и сохранение настроек.

## Ограничения

Видеозапись не содержит исходного кода, полной структуры файлов и подключения к серверу. Поэтому данные аккаунтов, уведомлений, процессов, агентов и связей на карте — **демонстрационные**. Реализованное поведение имитирует видимые операции, но не заменяет оригинальную серверную логику TRACKTOR и не претендует на полную пиксельную идентичность.
