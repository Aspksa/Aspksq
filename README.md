# TRACKTOR — локальная версия для одного пользователя

Командный центр и интерактивная карта «Второй мозг», реконструированные по видео.
Данные хранятся в SQLite на вашем компьютере. Регистрация, Supabase, интернет и отдельная установка СУБД не нужны.

## Запуск на Windows

1. Установите **Python 3.9 или новее** с https://www.python.org/downloads/. При установке включите **Add Python to PATH**.
2. Распакуйте проект целиком в папку, в которую у вас есть право записи.
3. Дважды нажмите **Aspksa.bat**. Откроется http://127.0.0.1:4173/.
4. Оставьте окно сервера открытым, пока работаете. Чтобы остановить сервер, нажмите в нём **Ctrl+C**.

BAT запускает `server.py`, который обслуживает сайт и локальную базу. Открывать `index.html` напрямую или использовать `python -m http.server` для работы с базой не нужно.

На Linux/macOS или из терминала:

```bash
python3 server.py --open-browser
```

На Windows вместо `python3` можно использовать `py -3`.
Если порт занят, закройте старое окно сервера либо запустите `py -3 server.py --port 4174 --open-browser`.
Путь к базе определяется относительно папки проекта, независимо от текущей папки терминала.

## Где данные

При первом запуске автоматически создаётся **data/tracktor.sqlite3** с таблицами клиентов, проектов, навыков, процессов, задач, уведомлений и настроек. Один пользователь, без паролей и аккаунтов. Сервер принимает подключения только с этого компьютера через `127.0.0.1`.

Существующие демонстрационные клиенты (19), проекты (20) и процессы (6) копируются в новую базу один раз из `seed-data.json`. Повторный запуск не перезаписывает данные и не добавляет дубликаты. Это исходные примеры из видеозаписи, а не ваши реальные клиенты.

Из интерфейса можно добавлять собственные навыки и сохранять настройки карты. Кнопка **Обновить** перечитывает данные из базы. Редактор клиентов/проектов/процессов в интерфейсе пока отсутствует; эти таблицы можно редактировать SQLite-инструментами при остановленном сервере. Список уведомлений и задачи пока не подключены к виджетам интерфейса.

Настройки также сохраняются в браузере как запасная копия. При запуске настройки из SQLite имеют приоритет.

## Резервная копия и перенос

- Нажмите **БАЗА → Скачать резервную копию**. Скачается согласованный снимок `tracktor-backup.sqlite3`, даже если приложение работает.
- Для восстановления остановите сервер, сохраните текущую базу отдельно и замените `data/tracktor.sqlite3` резервной копией, переименовав её в `tracktor.sqlite3`. Затем запустите BAT.
- Для переноса на другой компьютер скопируйте папку проекта вместе с `data` и установите там Python.
- При обновлении файлов проекта сохраняйте свою папку `data`. Она исключена из Git и не должна попадать в публичный репозиторий.

В существующей конфигурации Supabase URL и ключ были пустыми; перенос данных из ранее подключённого облачного проекта не выполняется.

## Интерфейс

- Командный центр: клиенты, карта, календарь, команда, навыки и процессы.
- «Второй мозг»: кольца, круг, соты и силовая раскладка; поиск, темы, фильтры, перемещение и масштабирование; экспорт PNG.
- `+` / `-` — масштаб, `0` — центрирование, `/` — поиск, `Esc` — закрытие карточки, `?` — справка.
- Адаптивная версия для телефона и компьютера.

AI-навыки и процессы **не выполняют автоматизацию**: для этого нужен отдельный исполнитель. Файлы карты, команда, воронка и часть виджетов остаются демонстрационными. Подробности исходной реконструкции — в [VIDEO_AUDIT_RU.md](VIDEO_AUDIT_RU.md).

## Проверки

Для приложения нужны только Python и современный браузер. Node.js и Playwright используются исключительно в тестах.

```bash
python3 -m unittest discover -s tests -p 'test_*.py' -v
node --check app.js
node --check database.js
node tests/smoke.mjs
```

Браузерные проверки на ширинах 390, 740, 1024 и 1440 пикселей:

```bash
npm install --no-save playwright
npx playwright install chromium
node tests/visual.cjs
```

Тесты запускают сервер с отдельной временной базой и не затрагивают `data/tracktor.sqlite3`. Проверяются сохранение после перезапуска, резервное копирование, валидация запросов, интерфейс и добавление навыка без регистрации. Снимки сохраняются в `artifacts/screenshots`.

## Структура

- `Aspksa.bat` — запуск на Windows.
- `server.py` — HTTP-сервер и SQLite API на стандартной библиотеке Python.
- `sqlite-schema.sql`, `seed-data.json` — создание новой базы и начальные примеры.
- `database.js` — браузерный клиент локального API.
- `index.html`, `styles.css`, `app.js` — интерфейс и карты SVG.

Локальному API нужен работающий Python-сервер. GitHub Pages не запускает Python и не предоставляет доступ к вашей SQLite-базе; workflow проекта выполняет проверки без публикации локальной версии.
